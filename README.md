# 🎯 Guess The Number Game

A simple and interactive number guessing game built using **HTML, CSS, and JavaScript**. Challenge yourself to guess a randomly generated number between 1 and 100 in as few attempts as possible!

### 🎮 Game Interface

The game provides an input field where players enter their guesses, submit their answers, and track their attempts.

### 🏆 Winning Screen

When the player guesses the correct number, a congratulatory message appears along with the total attempts and points earned.

## ✨ Features

- 🎲 Random number generation between 1 and 100
- 🔢 User input for number guessing
- 📊 Total attempt counter
- 📝 Previous guess tracking
- 🏆 Winning message when the correct number is guessed
- ⭐ Points awarded after winning
- 🔄 Play Again option to start a new game
- 🚪 Quit option to exit the current game
- 🎨 Simple and colorful user interface

## 🛠️ Technologies Used

- **HTML5** — Structures the game interface.
- **CSS3** — Styles the game layout, colors, buttons, and winning screen.
- **JavaScript (ES6+)** — Implements the game logic, random number generation, guess validation, attempt tracking, and game interactions.

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Open the main HTML file in your browser, or use the Live Server extension in VS Code.

## 🎮 How to Play

1. Start the game.
2. Enter a number between 1 and 100.
3. Click the **Submit** button.
4. Continue guessing until you find the correct number.
5. Check your total attempts and points after winning.
6. Click **Play Again** to start another round.
